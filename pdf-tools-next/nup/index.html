모두카피에서 출력해 보내 드립니다.

이 파일로 인쇄 주문하기 책으로 만들기 주문
  1. ①위에서 PDF를 받습니다.
  2. ②새 탭으로 열리는 주문서의 파일 첨부에 받은 PDF를 올립니다.

파일은 주문서로 자동 전달되지 않습니다. 받은 PDF를 직접 첨부해 주세요.

사용 방법
  1. PDF 파일을 선택하거나 끌어다 놓습니다.
  2. ‘여러 쪽 모아찍기’ 또는 ‘같은 쪽 여러 개 찍기’를 고르고, 미리보기에서 인쇄될 모습을 확인합니다.
  3. ‘PDF 만들기’를 누른 뒤 ‘PDF 받기’로 저장합니다.
  4. 인쇄할 때는 프린터 설정에서 ‘실제 크기(100%)’, ‘한 면에 1쪽’을 선택하세요. 모아찍기를 한 번 더 고르면 두 번 줄어듭니다.
결과 확인과 책임 안내

무료로 제공하는 보조 도구입니다. 받은 PDF의 모든 쪽을 원본과 비교해 확인한 뒤 사용·인쇄해 주세요. 원본 파일과 이미 접수된 주문 원고는 바뀌지 않습니다.

링크·책갈피와 입력 양식의 입력 기능은 결과에 남지 않습니다(보이는 내용은 그대로 인쇄됩니다). 색상 변환이나 재단 여백(도련) 만들기는 하지 않습니다.
