어떤 PDF 작업이 필요하세요?

하려는 일을 고르면 파일 선택부터 받기까지 한 화면에서 끝납니다.

무료로그인 없이편집·인쇄 배치는 파일이 내 기기 안에서만 처리

  • PDF 합치기

  • 4쪽 모아찍기
  • 같은 쪽 여러 개
  • 워드 → PDF
  • 사진 → PDF

인쇄용으로 배치하기

종이를 아끼거나 양면 인쇄에 맞게 쪽을 배치합니다.

  • 2쪽 모아찍기A4 한 장에 2쪽씩 나란히
  • 4쪽 모아찍기A4 한 장에 4쪽씩
  • 같은 쪽 여러 개 찍기같은 쪽을 한 장에 2개 · 4개 반복
  • 양면 인쇄 맞춤파일마다 새 장에서 시작하게 빈 뒷면 넣기
  • 쪽 번호 넣기원하는 위치에 쪽 번호 표시
  • A4 크기로 맞추기크기가 섞인 문서를 한 규격으로
  • 소책자 배치반 접어 책이 되게 쪽 순서 배치준비 중

합치기 · 나누기

여러 파일을 하나로, 한 파일을 여러 개로.

  • PDF 합치기여러 PDF를 순서대로 한 파일로
  • PDF 나누기쪽 범위대로 여러 파일로
  • 필요한 쪽만 뽑기고른 쪽만 새 PDF로 저장

쪽 정리

순서, 방향, 빈 쪽을 손봅니다.

  • 쪽 순서 바꾸기쪽을 원하는 순서로 옮기기
  • 쪽 순서 뒤집기마지막 쪽이 맨 앞으로 오게
  • 쪽 삭제필요 없는 쪽 지우기
  • 쪽 회전누운 쪽을 바로 세우기
  • 빈 쪽 넣기원하는 자리에 빈 쪽 추가
  • 쪽 복제같은 쪽을 여러 번 넣기
  • 여백 자르기표시한 여백만큼 잘라내기

다른 파일 → PDF

  • 워드 → PDFDOCX 문서
  • 엑셀 → PDFXLSX 시트
  • 파워포인트 → PDFPPTX 슬라이드
  • 사진 → PDFJPG · PNG · TIFF
  • 한글(HWP) → PDF한글 프로그램에서 [파일 > PDF로 저장하기]로 저장한 뒤 올려 주세요.준비 중

파일 준비가 끝났나요?

완성한 PDF 그대로 인쇄를 맡기세요. 주문 화면에서 파일을 첨부하면 됩니다.

칼라·흑백 출력 주문책 만들기
내 파일은 어떻게 처리되나요?

편집·인쇄 배치는 이 브라우저 안에서만 처리하며 파일을 서버로 보내지 않습니다.

다른 파일 → PDF 변환은 모두카피의 격리된 임시 공간에서 처리하고, 결과를 드린 뒤 정리합니다.

파일 처리·개인정보 안내

결과 확인과 책임 안내

무료로 제공하는 보조 도구입니다. 글꼴·줄바꿈·쪽 순서가 원본과 달라질 수 있으니, 받은 PDF를 원본과 비교해 확인한 뒤 사용·인쇄해 주세요. 원본 파일과 이미 접수된 주문 원고는 바뀌지 않습니다. 자세한 책임 제한 안내는 각 도구 화면에 있습니다.

파일 크기 한도

편집은 선택한 파일 합계 2.5GB까지, 변환은 파일 1개당 1GB까지입니다. 기기 메모리에 따라 한도 안에서도 멈출 수 있습니다.
