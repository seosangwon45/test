# start/ — PDF 도구 시작 화면 (작업 고르기)

할 일 고르기 → 파일 → 받기 흐름의 첫 화면입니다. 서버 코드 없이 정적 파일 3개로 동작합니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체(로고 SVG 포함) |
| `start.css` | 스타일. 외부 글꼴·CDN 요청 없음 |
| `start.js` | 작업 이름 검색(타일 필터). 꺼져 있어도 모든 타일이 보입니다 |
| `shots/` | 점검 스크린샷 (배포 대상 아님) |

## 올릴 위치
`/pdf-tools/start/` 를 기준으로 만들었습니다. 새 모아찍기 화면(`nup/`)의 "전체 도구" 링크와 쇼핑몰 입구 블록의 "전체 도구 보기"가 모두 `/pdf-tools/start/` 를 가리킵니다. 다른 주소에 올리면 그 두 곳의 링크도 함께 바꿔야 합니다.

## 타일이 가는 곳
| 타일 | 주소 | 지금 상태 |
|---|---|---|
| 2쪽 모아찍기 / 4쪽 모아찍기 / 같은 쪽 여러 개 찍기 | `/pdf-tools/nup/?job=nup2` · `nup4` · `repeat2` | **`nup/` 배포 후 열림** (현재 운영 사이트는 404) |
| 양면 인쇄 맞춤, 쪽 번호 넣기 | `/pdf-tools/print/` | 지금 열림 |
| PDF 합치기·나누기·뽑기, 쪽 순서 바꾸기·뒤집기·삭제·회전·빈 쪽 넣기·복제, 여백 자르기, A4 크기로 맞추기 | `/pdf-tools/basic/?job=merge` `split` `extract` `organize` `reverse` `delete` `rotate` `insertblank` `duplicate` `crop` `resize` | 지금 열리지만 **항상 '합치기'로 시작**. 편집 화면 딥링크 패치 후 정확히 열림 |
| 워드·엑셀·파워포인트·사진 → PDF | `/pdf-tools/converter/` | 지금 열림 |
| 한글(HWP) → PDF | 링크 없음 | "준비 중" + 한글에서 PDF로 저장하는 방법 안내 |
| 소책자 배치, PDF 용량 줄이기, PDF → JPG, 암호 풀기·걸기 | 링크 없음 | "준비 중" (누를 수 없음) |
| 로고, 주문하러 가기 | `/shop/` | |
| 칼라·흑백 출력 주문 / 책 만들기 | `/shop/item.php?it_id=1441618748` / `it_id=1437511967` | |

쓰지 않은 편집 작업 값: `number`(쪽 번호는 인쇄 준비 화면으로 연결), `appendblank`(‘빈 쪽 넣기’ 하나로 합침).

## 검색
- 타일 이름과 숨은 낱말(`data-k`)에서 찾습니다. 예: "합치", "모아", "워드", "페이지 번호", "hwp".
- Enter: 첫 결과로 초점 이동. Esc 또는 × 버튼: 지우기. 결과 개수는 화면 낭독기에 알립니다.
- `?q=낱말` 로 열면 미리 찾아 둔 상태로 시작합니다.
- 새 타일을 넣을 때는 `<li data-k="이름 찾을낱말들">` 을 같이 적습니다.

## 글꼴
`Pretendard` 를 먼저 지정하고 없으면 시스템 한글 글꼴을 씁니다. 쇼핑몰은 Pretendard를 외부 CDN(jsdelivr)에서 불러오지만, 이 화면은 외부 요청을 하지 않으므로 기기에 Pretendard가 없는 방문자는 시스템 글꼴(맑은 고딕, Apple SD 산돌고딕 등)로 보입니다. 쇼핑몰과 완전히 같게 하려면 Pretendard woff2를 서버에 올리고 `start.css` 맨 위에 `@font-face` 를 추가하면 됩니다.

## 적용 / 되돌리기
1. `index.html`, `start.css`, `start.js` 를 `/pdf-tools/start/` 에 올립니다(새 폴더라 기존 파일을 덮어쓰지 않음).
2. 주소로 직접 열어 확인한 뒤, 쇼핑몰 입구 블록(`../shop-entry/`)을 교체합니다.
3. 되돌리기: 폴더를 지우거나 이름을 바꾸면 끝입니다. 기존 `/pdf-tools/` 허브는 건드리지 않습니다.

CSS·JS를 고치면 `index.html` 의 `?v=20261117a` 값을 바꿔 캐시를 새로 고칩니다.
